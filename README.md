\# ✈️ Full-Stack AI Travel Planner



An AI-powered web application that generates personalized travel itineraries based on destination, duration, budget, and user preferences.



\## 🚀 Tech Stack

\- \*\*Frontend\*\*: HTML5, CSS3, JavaScript (Fetch API), Marked.js

\- \*\*Backend\*\*: Node.js, Express.js

\- \*\*AI Integration\*\*: Azure OpenAI API (`gpt-4.1-mini`)

\- \*\*Environment Management\*\*: Dotenv, Gitignore



\## ✨ Key Features

\- Dynamic itinerary generation based on user inputs.

\- Clean Markdown-to-HTML rendering with custom slate styling.

\- One-click \*\*Print\*\* and \*\*Save as PDF\*\* capabilities.

\- Secure environment configuration separating secrets from codebase.
